CryptoACTION - Combating cryptocurrency‑facilitated crime and terrorism with interoperable, trustworthy, AI‑enhanced collaborative tools, and improved information sharing, operations, and training for law‑enforcement agencies (LEAs)

## Short description
CryptoACTION delivers interoperable, trustworthy, AI‑enhanced collaborative tools, improved information sharing and operations, and practical training to help LEAs detect, investigate, and counter cryptocurrency‑facilitated crime and terrorism (CFCT). The project combines interdisciplinary research, LEA‑driven tool development, a federated anti‑CFCT dataspace, capacity building, and regulatory engagement to deliver sustainable, cross‑border investigative and prosecutorial capabilities.

## Objectives
1. Conduct an interdisciplinary study of:
    - current and emerging CFCT trends,
    - the international regulatory landscape,
    - the anti‑CFCT operational ecosystem (tools, LEA operations, collaboration pathways).  
      The study will identify strengths and weaknesses and produce evidence‑based, impact‑assessed recommendations.

2. Deliver improved lawful tools and methodologies shaped by LEA requirements for detecting and investigating CFCT, identifying involved parties, and tracing funds for lawful seizure and processing - prioritizing interoperability, collaboration, and alignment with Trustworthy AI principles.

3. Engage LEAs and stakeholders to build an international federated anti‑CFCT dataspace and provide tools that strengthen global cooperation mechanisms (INTERPOL / Europol integration).

4. Create the world’s first “cryptorange” and design collaborative capacity‑building methodologies, curricula, and training for LEAs, prosecutors, and the judiciary covering investigations, seizure/handling of cryptocurrency assets, collaboration, and multimodal evidence evaluation.

5. Co‑design and validate tools, automated benchmarks, and training with LEAs, Europol (including the Europol Innovation Lab), and INTERPOL, and contribute to regulatory recommendations.

6. Promote sustainable collaboration between industry, academia, and governmental organisations and engage with aligned initiatives.

## Quick start (Vue 3 + Vite + TypeScript)

Prerequisites: Node.js >=16, npm or yarn

1. Create project
```bash
# npm
npm create vite@latest cryptoaction-frontend -- --template vue-ts

# or yarn
yarn create vite cryptoaction-frontend --template vue-ts
```

2. Install dependencies
```bash
cd cryptoaction-frontend
npm install
```
